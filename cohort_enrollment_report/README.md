# Monthly ASCEND Cohort Enrollment Report
Run this file at the beginning of the month to report on the enrollment numbers for each cohort. Script will output an .xlsx file with Cohort Name, Month, English Enrollments, and French Enrollments.
<br> Run from terminal: <br>
```python cohort_enrollments.py```

## Requirements
Requires a .env file containing:<br>
```
MOODLE_USERNAME="your_username"
MOODLE_PASSWORD="your_password"
```
Root folder should have folders for data and reports.
