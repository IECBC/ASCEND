# Monthly ASCEND Cohort Enrollment Report
Run this file at the beginning of the month to report on the enrollment numbers for each cohort. Script will output a CSV file with Cohort Name, English Enrollments, and French Enrollments.
<br> Run from terminal: <br>
```python cohort_enrollments.py```

## Requirements
Requires a .env file containing:<br>
```
MOODLE_USERNAME="your_username"
MOODLE_PASSWORD="your_password"
```
